北海职业卫生数据处理平台 · Windows 单机安装版
================================================

适用：Windows 10 / 11，64 位。
安装及日常运行均可离线完成；不需要另装 Java、Node.js、MySQL 或 Docker。

首次使用
1. 双击 BHFYZX-Setup-1.0.12-x64.exe，选择程序安装路径。
2. 选择是否“导入线上版本的测试数据”（默认勾选），然后安装。
3. 完成后启动，等待数据库初始化和所选测试数据导入，再打开浏览器。
4. 管理员账号：admin；默认密码：Test@345。可以直接登录使用。
5. 从旧单机版首次升级到本版时，admin 密码会设置为 Test@345；后续重启不会
   再次重置密码。如自行修改，请使用修改后的密码。

日常使用
- 双击桌面的“北海职业卫生数据处理平台”即可打开。
- 关闭启动窗口后，系统继续在托盘运行；关闭浏览器不会停止服务。
- 需要停止时，在启动窗口或托盘菜单点击“停止并退出”。
- 本版本供本机使用，不向局域网开放。

数据与备份
- 数据目录：%LOCALAPPDATA%\BHFYZX\Data
- 数据库、报告、附件、首次登录信息均保存在该目录。
- 点击启动窗口的“备份数据”，选择其他目录保存 ZIP；备份时会短暂暂停服务。
- 恢复备份：停止系统，先另行备份现有 Data 目录，再将备份 ZIP 完整解压到 Data
  目录（database、storage、installation.keys 等直接位于 Data 下），然后启动。
- installation.keys 是数据库访问凭据的一部分，请和数据库一起备份，不要删除。
- 覆盖安装新版和卸载程序均保留 Data 目录；重新安装可继续使用原有数据。
- 程序安装目录可以选择；业务数据仍独立保存在上述 Data 目录，便于升级保留。

测试数据
- 安装包内置线上版本业务快照，安装及导入时不需要连接服务器。
- 来源：2026-09-17 线上版本，含可见职业卫生项目 4 个、放射检测案例 19 个，
  以及相关基础资料、历史记录和 60 个可读取附件。不含线上账号或登录凭据。
- 线上已失效的 22 个历史文件路径对应记录不作为可用附件导入。
- 在启动窗口点击“导入测试数据”或“删除测试数据”，完成后刷新浏览器。
- 同一批数据重复导入不会产生副本；删除后可重新导入。
- 删除只处理本功能导入的记录和附件，保留后来独立录入的业务数据。
- 若新增业务引用了测试单位、项目或人员等资料，系统会取消删除并提示解除引用。
- 不勾选安装选项表示本次不导入，不会清除原有测试数据或业务数据。
- 删除测试数据后重启不会自动重新导入；再次安装时勾选导入则会重新导入。

报告
- 报告模板已经内置，生成 DOCX 不需要安装 Office。
- 打开、编辑、打印 DOCX 请使用已有的 Word 或 WPS。
- 单机版直接生成报告，不在后台调用 Word/WPS。文档已设置打开时更新域；
  最终排版、目录和页码需在办公软件中更新并核对。

排查问题
- 启动窗口可以直接打开数据文件夹，运行日志在 logs 子目录。
- 默认访问地址为 http://127.0.0.1:18788，端口被占用时会自动选择其他端口。
  请以启动窗口显示的地址为准。
- 如安装包提示发布者未知：此构建尚未使用商业代码签名证书签名。

本安装包仅安装当前 Windows 用户使用的程序，不要求管理员权限。

操作手册
- 在启动窗口点击“下载详尽手册（Word）”或“下载简明指引（Word）”，选择保存位置。
- 系统左侧“帮助中心”下方可展开“操作手册下载”；帮助中心内也可下载。
- 两份手册已内置，离线可用；均包含 EXE 安装、测试数据、备份和业务操作说明。
