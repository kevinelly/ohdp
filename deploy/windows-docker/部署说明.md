# BHFYZX Windows Docker 完全离线部署说明 V1.0.6

## 从 V1.0.5 保留数据升级

1. 不要删除原 V1.0.5 目录和 Docker 数据卷。
2. 将 V1.0.6 完整解压到 `R:\BHFYZX-Windows-Docker-Offline-V1.0.6`。
3. 双击 `deploy\windows-docker\升级系统.bat`。
4. 脚本会复用原 `.env`，导入新镜像，并使用同一个 `bhfyzx` Compose 项目重建容器。
5. MySQL、报告和附件数据卷不会被删除。

本部署包采用 Windows 10/11 + WSL 2 + Docker Desktop。系统仍运行在 Linux 容器中，共三个长期运行容器：Web、API、MySQL。部署包已包含三个可运行镜像，**首次安装及以后运行均不需要互联网**。

只有 Web 端口 `8088` 暴露给 Windows；API 和 MySQL 仅在 Docker 内部网络通信。数据库、报告和附件使用 Docker 卷持久化，停止或重建容器不会自动删除数据。系统不使用云数据库或其他在线服务。

## 一、电脑要求

- Windows 10 64 位（22H2，内部版本 19045）或 Windows 11 64 位，且仍处于微软支持期。
- BIOS/UEFI 已开启 CPU 虚拟化。
- 建议 4 核 CPU、16 GB 内存。
- C 盘建议保留 20 GB；R 盘安装时至少保留 10 GB，作为长期业务数据盘建议保留 100 GB 以上。
- 应在断网前准备好本部署包，并预先安装 WSL 2 和 Docker Desktop。

不需要另外安装 Java、Node.js、Maven、Nginx 或 MySQL；也不需要登录 Docker 账号。

> “完全离线”是指目标机已经具备 WSL 2 和 Docker Desktop 后，BHFYZX 的首次安装与运行完全断网。如果目标机连 WSL 2 和 Docker Desktop 都未安装，应提前从官方渠道准备对应的离线安装介质。

> Docker Desktop 不适合无人登录的 Windows Server 后台服务场景。如果目标是 Windows Server，应改用独立 Linux 虚拟机或 Linux Docker 主机。

## 二、准备 WSL 2

如果当前电脑已经能正常启动 Docker Desktop，可跳过本节。以下在线命令只能在断网前执行；完全断网的新电脑应使用事先准备的 WSL 离线安装介质。

1. 右键开始菜单，选择“终端（管理员）”或“PowerShell（管理员）”。
2. 执行：

   ```powershell
   wsl --install
   ```

3. 命令完成后重启 Windows。
4. 重启后执行：

   ```powershell
   wsl --update
   wsl --set-default-version 2
   wsl --version
   ```

如果 `wsl --install` 下载一直卡住，可以执行 `wsl --install --web-download`。

## 三、准备 Docker Desktop

如果已经安装并显示 Engine running，可跳到第四节。断网前应从 Docker 官方网站下载并保存 Docker Desktop for Windows 安装程序：<https://docs.docker.com/desktop/setup/install/windows-install/>
2. 安装时选择 WSL 2 后端。
3. 启动 Docker Desktop，等待状态变为 Running。
4. 打开 Settings → General，确认启用 **Use the WSL 2 based engine**。
5. 确认使用的是 **Linux containers**。
6. 按本项目要求，在 Settings → Resources → Advanced → Disk image location 中把数据位置设为 `R:\DockerData\DockerDesktopWSL`。如果选择的是 `R:\DockerData`，Docker Desktop 自动追加子目录也属正常。不要手工剪切 Docker 的 WSL 数据文件。

打开 PowerShell 验证：

```powershell
docker version
docker compose version
docker info --format '{{.OSType}}'
```

最后一条命令应输出 `linux`。

## 四、解压和首次安装

1. 将整个压缩包解压到固定目录，推荐 `R:\BHFYZX-Windows-Docker-Offline-V1.0.6`。
2. 不要只复制 BAT，也不要直接在 ZIP 压缩包内运行文件。`deploy\windows-docker\images\bhfyzx-offline-images.tar.gz` 及其 `.sha256` 文件必须保留。
3. 启动 Docker Desktop。
4. 在根目录双击 `01-首次安装.bat`。
6. 脚本会自动完成以下工作：
   - 校验离线镜像包 SHA-256，防止文件复制不完整；
   - 检查 Docker Desktop、Linux containers、Compose、端口和磁盘空间；
   - 生成本机专用的数据库密码和管理员初始密码；
   - 从本地文件导入 MySQL、API、Web 三个镜像，不执行任何下载或构建；
   - 创建 MySQL、API、Web 三个容器；
   - 创建数据库、报告和附件持久化卷；
   - 等待系统就绪并打开浏览器。
7. 首次校验和导入通常需要数分钟，取决于 R 盘速度；中途不要关闭窗口或 Docker Desktop。
8. 安装完成后浏览器打开：<http://localhost:8088>
9. 管理员用户名默认为 `admin`，随机初始密码会显示在安装窗口，也保存在同目录的 `.env` 文件中。
10. 首次登录后立即修改管理员密码。

如 `8088` 已被占用，可在该目录打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -WebPort 8090
```

## 五、日常操作

| 操作 | 文件 |
|---|---|
| 启动系统并打开浏览器 | `启动系统.bat` |
| 停止系统但保留数据 | `停止系统.bat` |
| 查看三个容器状态 | `查看状态.bat` |
| 查看实时日志 | `查看日志.bat`，按 Ctrl+C 退出 |
| 备份数据库、报告和附件 | `备份数据.bat` |

Docker Desktop 必须保持启动。三个容器都配置为 `unless-stopped`，Docker Desktop 重启后会自动恢复运行。启动和重启脚本均强制使用本地镜像，不会拉取网络镜像。

不要执行 `docker compose down -v`、`docker volume prune` 或在 Docker Desktop 中删除带有 `bhfyzx` 名称的数据卷，这会删除业务数据。

## 六、备份

1. 双击 `备份数据.bat`。
2. 备份文件生成在 `deploy\windows-docker\backups` 下。
3. 每个 ZIP 备份包含：
   - MySQL 逻辑备份 `database.sql`；
   - 报告和附件 `storage.tar.gz`；
   - 部署密码文件 `deployment.env`；
   - SHA-256 校验文件。
4. 将备份 ZIP 复制到另一块磁盘或受控备份位置。备份中含数据库密码，应限制访问权限。

建议至少每日备份一次，并保留最近 7–30 份。升级程序前必须先做一次备份。

## 七、让局域网其他电脑访问

1. 确认当前 Windows 网络类型为“专用网络”或已加入域。
2. 右键或双击 `开放局域网访问.bat`，接受管理员权限提示。
3. 脚本只对 Domain/Private 网络和本地子网开放 Web 端口，不开放 API、MySQL。
4. 其他电脑使用脚本显示的地址，例如 `http://192.168.1.20:8088`。

如果只在本机使用，不需要运行该脚本。

## 八、故障处理

### 提示找不到 docker

Docker Desktop 未安装，或安装后尚未重新登录 Windows。安装并启动 Docker Desktop，再重新运行。

### Docker Desktop 无法启动

在管理员 PowerShell 执行：

```powershell
wsl --update
wsl --shutdown
```

然后重新启动 Docker Desktop。

### 8088 端口被占用

执行：

```powershell
Get-NetTCPConnection -LocalPort 8088
```

关闭占用程序，或用其他端口重新安装。

### 页面打不开或容器 unhealthy

双击 `查看状态.bat`，然后双击 `查看日志.bat`。正常状态应为三个容器均为 running/healthy。

### 提示离线镜像不存在或 SHA-256 校验失败

说明部署包没有完整解压，或大文件复制过程中损坏。重新复制整个 ZIP，完整解压后再运行。不要单独复制 BAT 文件，也不要修改 `images` 目录内的文件。

### 断网时 Docker 提示拉取镜像

V1.0.6 的 `compose.yaml` 已设置 `pull_policy: never`，安装及日常启动命令也使用 `--pull never --no-build`。如仍提示拉取，请确认运行的是 `BHFYZX-Windows-Docker-Offline-V1.0.6`，而不是旧版部署目录。

### 忘记首次管理员密码

在 `deploy\windows-docker\.env` 中查看 `ADMIN_INITIAL_PASSWORD`。如果已经在网页中修改过密码，应以修改后的密码为准。

如果 `.env` 中的密码仍无法登录，通常是复用了旧数据库卷。双击 `重置管理员密码.bat`，脚本只重置本机 `admin` 账号，不会删除项目、报告或附件。使用窗口显示的临时密码登录后，应立即修改密码。
