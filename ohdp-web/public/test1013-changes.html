建议的对照路径

  1. 打开CT模块，进入状态检测案例。新版计算表会显示倾角及CT值线性“不适用”，CTDI不要求体模。
  2. 只填水CT值后计算。新版会列出其他缺项，提交审核不可用。
  3. 完整计算后修改一个读数并保存。新版会标记需要重新计算，不允许沿用旧结果。
  4. 在CT状态检测中将噪声录数设为4.5、4.5、4.5，层厚10 mm。新版得到0.45%并判为不符合；不符合结果仍可如实进入审批。
  5. 提交完整案例后，使用“退回修改”填写原因，再查看报告页的操作历史。
  6. 查看生成的报告：编号等于受理编号、质量控制表包含检测条件及不检测理由。历史已批准案例若没有新快照，应创建修订版重新审批。

尚需确认或提供的资料

  1. 幂函数是否带常数项c？PPT第23页写PV=aK^b，第24页逆变换含c。当前保留已有带c模型；需要确认正式拟合/逆变换公式。
  2. 低对比“百分比基线”如何换算细节数？PPT第29页给个/%选择，判定公式却是细节数差。当前支持个数基线；百分比基线缺公式时阻止直接判定。
  3. 时间响应修正及厂家DDI专用公式是什么？PPT第30页称“与之前提供一致”，这三份附件没有该推导。当前支持手工录入k2与厂家DDI计算值；自动推导须提供仪器响应、曝光参数的公式和样例。
  4. 正式报告采用哪一版经核定内容？CT样例有DR单位及防护控制值错置，PPT第60页倾角说明疑似复制管电压公式。当前用CT项目自身计算和规则；需确认最终表号、文字及适用设备模式。
  5. 请提供真实签章/资质标识及授权人员资料。已留签章位置，审批姓名来自登录账户；未代造签名图片或资质标识。仪器证书和模体厂家值需录入实际资料。
  6. 其他设备类别的检测指标、模板及查询范围？PPT菜单和综合查询提到其他设备，但三份附件只详述CT/DR。CBCT、DSA、乳腺、牙科等需独立指标和模板，当前综合检测查询支持CT/DR。
  7. 点位图是否为签发必填项？PPT没有给出明确强制条件。当前允许未上传并在报告注明；若机构要求必填，可增加提交校验。

业务核定事项

机构受控表号、真实签章、资质、仪器证书、模体参数及厂家规定值仍需检测机构核定。模板保留提供的原版封面封二并生成动态正文并修正CT错配内容，软件测试案例均为虚构数据。牙科CBCT、高分辨扫描的特殊评价及其他设备类别应使用独立确认的规则，不套用普通CT项目。
