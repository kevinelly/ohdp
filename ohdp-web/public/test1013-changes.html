建议的对照路径

  1. 打开CT模块，进入状态检测案例。新版计算表会显示倾角及CT值线性“不适用”，CTDI不要求体模。
  2. 只填水CT值后计算。新版会列出其他缺项，提交审核不可用。
  3. 完整计算后修改一个读数并保存。新版会标记需要重新计算，不允许沿用旧结果。
  4. 在CT状态检测中将噪声录数设为4.5、4.5、4.5，层厚10 mm。新版得到0.45%并判为不符合；不符合结果仍可如实进入审批。
  5. 提交完整案例后，使用“退回修改”填写原因，再查看报告页的操作历史。
  6. 查看生成的报告：编号等于受理编号、质量控制表包含检测条件及不检测理由。历史已批准案例若没有新快照，应创建修订版重新审批。

尚需确认或提供的资料

  1. 幂函数是否带常数项c？PPT第23页写PV=aK^b，第24页逆变换却为K=[(PV-c)/a]^(1/b)，两者只有c=0时对应。选择不同模型会改变拟合系数、R²和响应均匀性的剂量换算。当前保留已有带c模型；需要检测机构确认拟合及逆变换使用同一套公式，并提供一组预期结果。
  2. 低对比“百分比基线”如何换算细节数？PPT第29页给个/%选项，结果和判定却使用“相差几个细节”。例如12个细节不能直接减去2.6%。当前支持个数基线、记录对比度，缺基线可建立首次基线；百分比基线不直接参与细节数判定。需要确认百分比究竟是对比度记录还是另一个判定指标，并提供其换算或判定规则。
  3. 时间响应修正及厂家DDI专用公式是什么？PPT第30页称计算“与之前提供一致”，附件中没有这一推导；第22页明确要求厂家提供DDI与入射空气比释动能的关系，却没有给出该关系。已有仪器响应时间并不足以唯一确定修正因子。当前支持手工录入k2及厂家DDI计算值、缺参考时按规定建基线。需要对应仪器/设备的公式、参数单位和一组人工核算样例，才能验证自动推导。
  4. 正式报告采用哪一版经核定内容？CT样例中诊断床定位写0.8kV、定位光精度写3.1mmAl，项目与单位不匹配；PPT第60页倾角说明又用了管电压偏差公式。已按CT项目自身计算和规则修正技术内容并保留原版布局；最终表号、版本年份、机构文字和适用设备模式属于正式模板的定稿资料，需要提供机构确认的版本。
  5. 请提供真实签章/资质标识及授权人员资料。两份原报告封二本身要求签章、批准人签字和资质标识。软件可以留位置、记录真实登录人及审批历史，但无法从样例推算实际授权人或生成真实签章。当前已保留签章位，审批姓名取账户；需要机构提供实际签章文件、人员授权信息，以及每次检测实际使用的仪器证书和模体厂家参考值。样例证书不能自动代表所有案例的实际仪器。
  6. 其他设备类别的检测指标、模板及查询范围？PPT第78页列出牙科机、乳腺设备等，但详细录入、算法和两份报告只覆盖CT/DR。其他类别需要确认项目目录、原始读数、检测类别矩阵、判定要求和报告模板；直接复用CT/DR会出现项目不适用。当前综合检测查询支持CT/DR；需要先确定下一批设备类别，再提供相应资料。
  7. 点位图是否为签发必填项？PPT第32、73页规定了上传格式和更换/删除操作，没有规定缺图在哪个环节阻止流程。强制与否会直接决定案例能否提交或签发。当前允许未上传，并在报告注明缺图；需要确认是否必填，以及在“提交复核”还是“批准/出报告”时检查。

业务核定事项

机构受控表号、真实签章、资质、仪器证书、模体参数及厂家规定值仍需检测机构核定。模板保留提供的原版封面封二并生成动态正文并修正CT错配内容，软件测试案例均为虚构数据。牙科CBCT、高分辨扫描的特殊评价及其他设备类别应使用独立确认的规则，不套用普通CT项目。
